# KStaff

A modern, lightweight, and scalable staff management plugin for Minecraft servers.

> ⚠️ KStaff is currently in early development. Features listed below are planned and subject to change.

## Planned Features

### Staff Utilities
- Packet-based vanish
- Silent chest interaction
- Staff mode system
    - Freeze players
    - Logout notifier
    - Inventory viewer
    - Player spectator mode
    - Actionbar support
    - API events
    - Scoreboard support
    - Native TAB integration
    - Fly toggle
    - Auto-disable staff mode on permission removal

### Communication
- Staff chat
    - Redis support

### Moderation Tools
- Player locator
    - Redis support

### Chat Utilities
- Alert system
    - Redis support
- Broadcast messages
- Clear chat
- Mute chat
- API events

## Goals

KStaff aims to provide:
- High performance
- Clean API design
- Cross-server communication support
- Modern staff tools
- Easy configuration and integration

## Status

This project is currently in the setup phase and under active development.
